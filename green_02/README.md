# Section 2 Business Card App

A single-page React Native app built with Expo for the CSCI 343 Section 2 App Programming Challenge.

## Assignment requirements included

- Donovan Green's profile image
- Name, email address, phone number, and GitHub page
- Clickable email, telephone, and GitHub links
- Styled single-page layout
- Organized component, screen, data, style, and utility folders
- PNG mockup saved at `docs/business-card-mockup.png`
- No `node_modules` folder in the submission package

The app loads Donovan's public GitHub profile photo and displays his initials if the online image cannot load.

## Run the project

```powershell
npm install
npx expo start
```

Scan the QR code with Expo Go. The project targets Expo SDK 54.
